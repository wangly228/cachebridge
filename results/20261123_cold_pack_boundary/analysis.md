# 新种子的三档重访实验

在单张 RTX 3090、Qwen3-4B BF16 上，冷请求打包候选在 0%、33⅓%、66⅔% 三档的整段 p95 TTFT 均低于同轮原生 A 和 overlap32。0% 档没有 GPU 前缀命中或 CPU 恢复，候选和 overlap32 都写入 128 块、计算 239,616 个 prompt tokens，只有候选允许队首下一个冷请求使用本步剩余预算。该档已经观察到打包收益。数据覆盖三个离散比例，其他输入布局与容量下的临界点未测。

| 淘汰后重访 | 原生 A p95（ms） | overlap32 p95（ms） | 候选 p95（ms） | 候选相对 A，95% 区间 | 候选相对 overlap32，95% 区间 |
| --- | ---: | ---: | ---: | --- | --- |
| 0% | 930.59 | 962.03 | 905.69 | −2.68% [−8.09%, −1.93%] | −5.86% [−9.94%, −5.23%] |
| 33⅓% | 970.67 | 970.62 | 905.05 | −6.76% [−9.68%, −5.57%] | −6.76% [−9.43%, −5.37%] |
| 66⅔% | 952.87 | 974.84 | 897.23 | −5.84% [−8.21%, −3.90%] | −7.96% [−9.78%, −6.74%] |

每档每臂 144 条请求。四个独立种子 2201–2204 各启动一个空缓存周期，每周期九波，每波四条 FIFO 请求，首次填充计入整段。每波两个 1,024-token 和两个 2,048-token 前缀，各附 128 个尾部输入，输出 128 tokens。GPU 实际 36 块，CPU 两臂各 64 块，每块 256 tokens，每步 prefill 上限 2,048 tokens。原生 A 使用同一个已预热引擎，其 CPU 策略关闭。按完整种子配对重采样 4,000 次，重算每臂所有所选请求的合并 p95 后取比值；区间反映这四个种子的离散性。[运行配置](engine.json) · [种子、顺序和输入](trace.json) · [逐档及逐种子数据](summary.json)

| --- | --- | ---: | ---: | ---: |
| 0% | 173.30 / 170.88 / 174.36 | 0 / 128 | 0 / 0 | 239,616 |
| 33⅓% | 169.23 / 175.36 / 179.48 | 128 / 240 | 21 / 48 | 206,848 |
| 66⅔% | 171.04 / 190.88 / 192.80 | 380 / 292 | 63 / 96 | 142,336 |

A 各档实际计算 239,616 个 prompt tokens。两 CPU 臂在各档的首波都累计写入 96 块。所有请求的抢占、保存失败、恢复失败计数均为零。各档各臂的进程 GPU 张量已分配峰值 9.042 GiB，进程 RSS 高水位 4.655 GiB，统计包含同一引擎预先分配的缓冲区。整批吞吐按 128 个输出 tokens × 请求数除以九波周期实际墙钟总和，含 prefill、decode、搬运及等待。[逐周期计时](cycles.jsonl) · [逐波内存](waves.jsonl) · [逐请求指标](requests.jsonl)

原始日志记录了 1,296 条正式请求，另有 324 条预热请求。根据实测日志，A、overlap32 和候选依次出现 4、8、7 种 prefill 的（query tokens，序列数）组合，全部在独立输入预热中出现。对总计 43,436 个调度步（含预热）进行无 GPU 的元数据回放，核对 FIFO、步形状、已占 GPU 块、逐请求命中/恢复/重算、CPU 驻留及淘汰计数。逐请求 TTFT 独立从入队与首个输出 token 时间戳重算，逐种子与整档 p95、六个配对区间和 8 份原始文件 SHA-256 校验通过。离线重建的 summary.json 与归档逐字节一致。[逐步记录](steps.jsonl) · [汇总与校验值](summary.json)

A 与 overlap32 有 320 条当波形状相同且无缓存前缀的请求，320/320 条得到完全相同的 128-token greedy 输出。候选和 A 的当波形状在 432 条对照上均发生变化，其中 259 条整个输出相同。候选和 overlap32 有 72 条当波形状相同但使用缓存的请求，其中 60 条整个输出相同；其余 360 条当波形状不同，其中 216 条整个输出相同。缓存最初计算时的批形状也可能影响后续输出。三档边界使用 A、overlap32、候选三组，匹配候选冷打包形状的额外原生参考保存在独立主正式实验中。[边界输出逐组计数](summary.json) · [主实验数值参考](../20261123_cold_pack_formal/reference/requests.jsonl)
